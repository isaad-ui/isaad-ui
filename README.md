## Featured projects

### [GitHub Developer Analytics](https://github.com/isaad-ui/github-developer-analytics)

A web app that analyses any public GitHub profile using the GitHub REST API. It shows profile details, language breakdown, repository statistics, top repositories and a searchable repository list. It also includes a Python terminal version.

`React` `Vite` `JavaScript` `Python` `GitHub API`

[Live demo](https://github-developer-analytics.netlify.app) · [Source code](https://github.com/isaad-ui/github-developer-analytics)

### [Website Uptime Monitor](https://github.com/isaad-ui/website-uptime-monitor)

A tool that checks whether a website is up. It reports the HTTP status code, response time and timestamp, and handles timeouts, SSL errors and connection failures. It started as a Python script and now has a FastAPI backend, a React dashboard with check history, and automated tests that run in GitHub Actions.

`Python` `FastAPI` `React` `pytest` `GitHub Actions`

[Live demo](https://website-uptime-monitor.netlify.app) · [Source code](https://github.com/isaad-ui/website-uptime-monitor)
